# Prácticas y proyectos HTML

Colección de actividades formativas de **HTML5** con páginas y recursos organizados por tareas. Incluye ejercicios de distintas unidades y páginas temáticas; es un repositorio de aprendizaje en evolución.

## Contenido

- `tarea*_ud2_amm.html`: páginas y ejercicios de la unidad 2.
- `tarea5_ud2_amm/`, `tarea6_ud2_amm/` y `tarea10_ud2_amm/`: actividades con sus recursos gráficos.
- `LM_examen_unidad2_amm/`: páginas y materiales asociados a una práctica/examen de la unidad.
- Otros archivos HTML de tareas, ampliación y actividades finales.

## Cómo revisar las páginas

Abre el archivo `.html` que quieras consultar directamente en un navegador. Algunas actividades cargan imágenes desde carpetas relativas; conserva la estructura del repositorio para que se muestren correctamente.

## Qué se practica

Estructura de documentos HTML, uso de elementos de marcado y organización de recursos locales. El contenido refleja ejercicios formativos; no presupone que todos los proyectos sean aplicaciones listas para producción.
