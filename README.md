# 🌐 HTML Projects and Assignments

Repository dedicated to the development, organization, and documentation of HTML exercises and assignments.

This repository contains practical activities focused on learning HTML (HyperText Markup Language), creating structured web pages, and understanding the fundamental principles of web development.

---

## 📌 Project Information

- **Repository Name:** `html-proyectos`
- **Subject Area:** Markup Languages
- **Main Technology:** HTML5
- **File Format:** `.html`
- **Hosting Platform:** GitHub

---

## 🎯 Objectives

The main objectives of this repository are:

- Understand the structure and syntax of HTML documents.
- Create well-structured web pages using HTML.
- Use HTML elements and tags correctly.
- Organize content using headings, paragraphs, lists, links, and other elements.
- Practice building web page structures.
- Develop good coding, organization, and documentation habits.
- Use GitHub to store, organize, and track changes to assignments.

## ▶️ How to Use This Repository

1. Open the repository on GitHub.
2. Select the HTML file you want to review.
3. Open the file to inspect its source code.
4. Download or clone the repository to work with the files locally.
5. Open an HTML file in a web browser to view the resulting page.

To clone the repository using Git, run:

```bash
git clone https://github.com/alejandromontillamurillo-cell/html-proyectos.git
```

Then, navigate to the project directory:

```bash
cd html-proyectos
```

Open the HTML files in your preferred code editor or web browser.

## ✅ Best Practices

The following practices are encouraged throughout the development of the assignments:

- Use a clear and consistent HTML structure.
- Include the appropriate document type declaration (`<!DOCTYPE html>`).
- Define the document language and character encoding.
- Use semantic HTML elements whenever appropriate.
- Keep the code properly indented and readable.
- Use descriptive and consistent file names.
- Test web pages in a browser.
- Organize project files into suitable folders.
- Save changes and maintain an organized history using GitHub.
